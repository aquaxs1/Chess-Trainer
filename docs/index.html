Chess Trainer

The download link always points to the newest release. No need to come back for updates — just re-download.

Install

  1. Download the zip above and extract it to a folder you will keep.
  2. Open chrome://extensions in Chrome or Edge.
  3. Turn on Developer mode (top right).
  4. Click Load unpacked and pick the extracted folder.
  5. Open a game on chess.com — refresh the tab if it was already open.

Minimum Chrome / Edge version: 116.

Hotkeys

KeyAction
Alt + XToggle trainer on/off
Alt + SStream mode — UI moves to a separate OS window
Alt + MCycle mode: All / Bots / Humans

Stream mode

Stream mode opens the panel in a separate OS-level window (Picture-in-Picture). The on-page arrow and panel disappear; every value — best move, evaluation bar, material, mate counter — moves into that window.

Capture methodSees the stream window?
OBS "Window Capture" of the chess.com windowNo
OBS "Game Capture"No
Discord "Share a window" / "Share an application"No
Zoom / Teams "Share application"No
YouTube Studio window captureNo
OBS "Display Capture" / full-screen screenshotYes

Rule: share the chess.com window, not your whole monitor. For display capture, move the stream window off the captured region or press Alt + X.

Modes

  • All — every chess.com page with a board. Default.
  • Bots — only /play/computer.
  • Humans — online, live, daily, analysis — everything except bots.
Using an engine against real opponents violates chess.com's rules and will get the account banned. Use at your own risk.
