Setup guide

Installed in about a minute

The extension isn't in the Chrome Web Store, so you load it by hand once.

  1. Download the ZIP

    Click "Download latest" above.

  2. Unzip it to a folder that stays

    Right-click the ZIP and choose "Extract all". Pick a permanent place such as Documents\chess-trainer. If you delete the folder later, the extension stops working.

  3. Open the extensions page

    Type chrome://extensions into the address bar. In Edge it's edge://extensions, in Brave brave://extensions.

  4. Turn on Developer mode

    Flip the "Developer mode" switch in the top-right corner (Edge: bottom-left).

  5. Load the folder

    Click "Load unpacked" and select the folder that directly contains manifest.json. The green pawn appears in your toolbar.

  6. Open any game

    Visit chess.com and start or open a game — bots, an online match, a live game, a daily game or the analysis board. If the tab was already open, reload it once with F5. The panel appears above the board as soon as it's your turn.

Chrome may show a "Disable developer mode extensions" notice on startup. That's normal for extensions from outside the store. Just close it.

Stream mode

Hidden from window capture

Press Alt + S and the panel leaves the chess.com page for a separate OS-level window (Picture-in-Picture). The arrow and the on-page panel vanish; the move, evaluation, material and mate counter move into that window.

Capture methodSees the stream window?
OBS "Window Capture" of the chess.com windowNo
OBS "Game Capture"No
Discord "Share a window" / "Share an application"No
Zoom / Teams "Share application"No
YouTube Studio window captureNo
OBS "Display Capture" / full-screen screenshotYes

Rule of thumb: share the chess.com window, not your whole monitor. For display capture, drag the stream window off the captured area, or hit Alt + X to turn the trainer off.

Using an engine against real opponents violates chess.com's rules and will get the account banned. Use at your own risk.
